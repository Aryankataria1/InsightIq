# InsightIQ 🧠
AI-Powered Business Analyst for Small Businesses

## What it does
- Upload any sales CSV
- Get automatic data analysis and visualizations
- AI-generated business insights powered by Gemini
- Sales forecasting using Machine Learning
- Downloadable PDF report

## Tech Stack
Python, Streamlit, Pandas, Plotly, Scikit-learn, Gemini API, FPDF

## Setup
1. Clone the repo
2. Create a .env file with your GEMINI_API_KEY
3. pip install -r requirements.txt
4. streamlit run insightiq.py
